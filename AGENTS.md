Keep it simple.

Focus on happy path, especially in testing.

Don't test every unhappy/failure scenario.  When writing automated tests, focus on the top small number of failure scenarios, and skip testing others.

When files get approx. larger than 1,500 lines, refactor the file into meaningful separate files.

Keep the README.md concise. Don't use it as a change log.  Significant design should be recorded in docs/design.md.
